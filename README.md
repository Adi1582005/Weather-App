# Weather-App
<h1>🌦️ Weather App Description :</h1>

A Weather App is a web-based application that provides real-time weather information for any location. It allows users to search for a city and instantly view current weather conditions such as temperature, humidity, wind speed, and weather status (e.g., sunny, cloudy, rainy).

The app integrates with a weather API to fetch live data and dynamically updates the user interface based on the weather conditions. It often includes features like weather icons, background changes, and error handling for invalid locations.

<h1>🚀 Key Features :</h1>

🔍 Search weather by city name

🌡️ Display temperature, humidity, and wind speed

☁️ Dynamic weather icons based on conditions

⚡ Real-time data using API integration

❌ Error handling for invalid input

📱 Responsive design for mobile and desktop

<h1>🛠️ Technologies Used :</h1>
HTML (structure)

CSS (styling)

JavaScript (logic & API handling)

Weather API (like OpenWeatherMap)
